# Shortest Path Router (Mini Google Maps)---

A simple C++ application that simulates a mini navigation system like Google Maps. It calculates
the shortest path and total distance between different locations.

## Features---
- Uses **Graph Data Structure** (Adjacency List) to connect different landmarks.
- Implements **Dijkstra's Algorithm** with a Min-Heap (Priority Queue) to find the fastest route.
- Built using **Object-Oriented Programming (OOPs)** principles in C++.

## How it Works
1. Enter the starting location and destination.
2. The program finds the absolute shortest route and distance in KM.
3. It prints the step-by-step route (e.g., Location A -> Location B).
